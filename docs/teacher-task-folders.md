# Папки заданий учителя

В разделе `/teacher/tasks` («База знаний») учитель создаёт личные папки,
например Present Simple. Внутри папки можно создавать несколько заданий.
Существующие задания остаются в «Без папки» и переносятся через список папок
в карточке задания. Перенос не меняет назначенные домашние работы.

В формах назначения домашней работы и создания/редактирования урока задания
фильтруются по папке и названию. Выбор сохраняется при смене фильтра;
выбранные задания отображаются отдельно и могут быть сняты с выбора.

## API

Все новые маршруты доступны только teacher и используют ID из сессии:

- `GET /tasks/folders` — личные папки.
- `POST /tasks/folders` с `{ name }` — создание папки.
- `PATCH /tasks/:id/folder` с `{ folder_id: uuid | null }` — перенос своего задания.
- `POST /tasks` принимает необязательный `folder_id` и проверяет владельца папки.

Составной внешний ключ запрещает связывать задания с папками другого учителя.
Доступ к таблице папок идёт только через backend; RLS включён, права
anon/authenticated отозваны. Имена папок уникальны внутри учителя без учёта
регистра и пробелов по краям.

## Выпуск и проверки

1. Применить `20260925112436_teacher_task_folders.sql`.
2. Выпустить backend из `zagran-easy-back`.
3. Выпустить frontend.

Backend: `npm test -- src/tasks/task-folders.spec.ts`,
`npx tsc -p tsconfig.build.json --noEmit --incremental false`.
Frontend: `npx tsc --noEmit`, ESLint изменённых файлов.
