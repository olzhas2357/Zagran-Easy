# Кэширование публичного каталога

`lib/api.ts` по умолчанию использует `no-store`. Авторизованные запросы,
мутации и персональные предложения не кэшируются; публичный GET включается
в Data Cache только с явно заданными `revalidate` или `tags`.

Публичные запросы из `lib/data.ts` имеют резервный TTL один час. Имена тегов
находятся в `lib/cache-tags.ts`. Server Actions инвалидируют соответствующие
теги и страницы после успешного изменения вузов, элементов их каталогов,
курсов и разделов. При импорте инвалидируются все данные вузов, поскольку
ответ импорта не содержит список изменённых slug.

Изменения через другие системы и прямые изменения в базе не вызывают эти
Server Actions и становятся видимыми после истечения TTL и следующего
обращения. Webhook для внешних изменений пока не настроен. Часовой TTL также
ограничивает устаревание вычисляемых по текущей дате признаков каталога.

Для проверки запускайте `node --test tests/cache-policy.test.mjs` и
`npm run build`. После развёртывания сравнивайте ISR Write Units и размеры
страниц в Vercel: фактический расход зависит от трафика, изменений и сжатия,
а не только от частоты ревалидации.
