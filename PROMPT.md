Работаем над существующим frontend-проектом ZagranEasy на Next.js, TypeScript и Tailwind CSS.

Необходимо создать временную тестовую страницу для изучения китайских иероглифов с использованием библиотеки:

https://github.com/chanind/hanzi-writer

## Цель

Проверить, подходит ли Hanzi Writer для будущего китайского языкового модуля ZagranEasy.

Тестовая версия должна продемонстрировать:

- отображение китайского иероглифа;
- анимацию порядка черт;
- тренировку написания;
- проверку правильности каждой черты;
- подсчёт ошибок;
- подсказки;
- изменение сложности;
- адаптивность для компьютера и телефона.

Backend и Supabase пока не подключать. Результаты попыток временно хранить только в состоянии страницы.

## Перед реализацией

1. Изучи структуру проекта.
2. Определи используемый package manager.
3. Найди существующие UI-компоненты и дизайн-токены.
4. Не меняй существующие страницы курсов.
5. Создай отдельную временную страницу, например:

```text
/staff/language/chinese/hanzi-test
```

Если структура маршрутов проекта отличается, выбери подходящий внутренний маршрут и объясни решение.

## Подключение библиотеки

Установи:

```bash
npm install hanzi-writer
```

Используй package manager проекта. Не подключай библиотеку одновременно через npm и CDN.

Поскольку Hanzi Writer работает с DOM, компонент должен быть клиентским:

```tsx
"use client";
```

Создавай экземпляр библиотеки внутри `useEffect` после появления DOM-элемента.

Учти React Strict Mode:

- не создавай несколько экземпляров для одного контейнера;
- перед повторной инициализацией очищай контейнер;
- при размонтировании отменяй активный quiz;
- при изменении иероглифа корректно вызывай `setCharacter()` или пересоздавай экземпляр;
- не допускай дублирования SVG.

## Интерфейс страницы

Страница должна содержать:

### Заголовок

```text
Лаборатория иероглифов
Изучайте порядок черт и тренируйте написание китайских иероглифов
```

### Информация об иероглифе

Показывать:

- иероглиф;
- pinyin;
- перевод;
- номер текущего задания;
- количество попыток;
- количество ошибок.

### Рабочая область

Размести Hanzi Writer внутри квадратной китайской сетки `米字格`:

- внешняя граница;
- вертикальная линия;
- горизонтальная линия;
- две диагональные линии;
- линии сетки должны быть светлыми и не мешать письму.

Рекомендуемый размер:

- desktop: 320 × 320 px;
- mobile: ширина контейнера, максимум 320 px.

### Режимы

Добавь два режима.

#### Демонстрация

Кнопки:

- «Показать порядок черт»;
- «Пауза»;
- «Продолжить»;
- «Показать иероглиф»;
- «Скрыть иероглиф»;
- «Показать контур»;
- «Скрыть контур».

Используй методы:

```ts
writer.animateCharacter();
writer.pauseAnimation();
writer.resumeAnimation();
writer.showCharacter();
writer.hideCharacter();
writer.showOutline();
writer.hideOutline();
```

#### Практика

Кнопки:

- «Начать писать»;
- «Начать заново»;
- «Показать подсказку»;
- «Следующий иероглиф».

Запускай:

```ts
writer.quiz()
```

Используй callbacks:

```ts
onMistake
onCorrectStroke
onComplete
```

Показывай:

- номер текущей черты;
- оставшееся количество черт;
- общее количество ошибок;
- сообщение о правильной черте;
- результат завершённой попытки.

## Уровни сложности

Добавь переключатель:

### Легко

```ts
showOutline: true
showHintAfterMisses: 1
leniency: 1.4
```

### Нормально

```ts
showOutline: true
showHintAfterMisses: 3
leniency: 1
```

### Сложно

```ts
showOutline: false
showHintAfterMisses: false
leniency: 0.7
```

При изменении сложности корректно перезапускай упражнение.

## Результат попытки

После завершения показывай карточку:

```text
Иероглиф: 我
Попытка завершена
Правильных черт: 7
Ошибок: 2
Время: 18 секунд
Результат: 80%
```

Для тестовой версии можно использовать простую формулу:

```ts
score = Math.max(0, 100 - totalMistakes * 10);
```

Обязательно подпиши, что это внутренний тестовый результат, а не официальная оценка качества каллиграфии.

Сохраняй список попыток в локальном state:

```ts
interface HanziAttempt {
  id: string;
  character: string;
  difficulty: "easy" | "normal" | "hard";
  totalMistakes: number;
  score: number;
  durationMs: number;
  completedAt: string;
}
```

Реализуй:

- загрузку данных иероглифа;
- успешную загрузку;
- ошибку загрузки;
- активную анимацию;

Во время загрузки показывай skeleton или spinner.

## Данные иероглифов

Для первого теста разрешается стандартная загрузка данных Hanzi Writer через jsDelivr.

Архитектуру компонента подготовь так, чтобы позднее можно было использовать собственный `charDataLoader` и хранить данные на сервере ZagranEasy.

Не загружай `all.json`, потому что полный файл данных слишком большой для обычной страницы.

## Дизайн

Сохрани визуальный стиль ZagranEasy:

- белые карточки;
- фирменный синий цвет;
- голубые акценты;
- мягкие границы;
- умеренные тени;
- крупная рабочая область;
- удобные кнопки для телефона;
- тёмная тема, если она уже поддерживается проектом.

На мобильном устройстве область рисования не должна прокручивать страницу во время проведения черты.

Используй `touch-action: none` только для области письма, а не для всей страницы.

## Ограничения

Не утверждай, что библиотека:

- распознаёт любой рукописный китайский текст;
- оценивает красоту каллиграфии;
- проверяет произношение;
- определяет перевод;
- заменяет преподавателя.

Hanzi Writer проверяет написание конкретного заранее выбранного иероглифа и соответствие ожидаемым чертам.

## Критерии готовности

Работа считается выполненной, если:

- библиотека устанавливается без конфликтов;
- тестовая страница открывается;
- отображаются семь тестовых иероглифов;
- анимация порядка черт работает;
- практика письма работает мышью и пальцем;
- ошибки подсчитываются;
- подсказки работают;
- можно менять сложность;
- отображается результат;
- можно перейти к следующему иероглифу;
- ошибки загрузки не ломают страницу;
- TypeScript собирается без ошибок;
- lint и build проходят;
- существующие страницы проекта не изменены.
