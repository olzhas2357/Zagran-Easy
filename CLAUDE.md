# Техническое задание: исправление страницы университетов

## 1. Главная задача

Необходимо исправить существующую страницу университетов и реализовать удобную структуру отображения университетов по странам. Сохранить текущий дизайн сайта, архитектуру, существующие страницы и работающий функционал, внося только необходимые изменения.

**Важно:** не переписывать проект с нуля, не создавать дубликаты страниц и не менять существующую структуру без необходимости.

## 2. Логика страницы университетов

### Общий каталог
При переходе в раздел «Университеты» пользователь должен видеть общий каталог университетов, как это работает сейчас.

Необходимо сохранить:
- существующий список университетов;
- текущую навигацию и переходы между страницами;
- работающую сортировку и фильтрацию;
- существующие данные и компоненты, если они уже реализованы.

### Страницы отдельных стран
При выборе страны пользователь должен переходить на соответствующую страницу с подробной информацией о стране и её университетах.

Для каждой страны должна быть своя страница по единому шаблону, например:

- Китай;
- Турция;
- Италия;
- другие страны, уже представленные на сайте.

### Структура страницы страны

1. **Информация о стране** — краткое описание системы образования, особенностей поступления, преимуществ обучения и другой полезной информации.
2. **Топ-20 университетов** — сначала отображать 20 наиболее значимых университетов страны.
3. **Остальные университеты** — выводить ниже отдельным списком, с возможностью просмотра полного каталога.
4. **Подробная информация** — карточки университетов должны содержать доступные данные: название, город, описание, направления обучения и другую существующую информацию.
5. **Навигация** — предусмотреть удобный возврат к общему каталогу и переход между странами.

Топ-20 необходимо определять на основе достоверного рейтинга или существующих данных проекта. Не назначать университеты в топ случайным образом.

## 3. Дизайн

Использовать текущую дизайн-систему сайта: цвета, типографику, компоненты, отступы и стили карточек.

Улучшить визуальную структуру страниц стран, если это необходимо, но не менять общий стиль сайта и дизайн других разделов.

Интерфейс должен быть аккуратным, современным, адаптивным и единообразным для всех стран.

## 4. Порядок работы

Перед внесением изменений:

1. Изучить текущую архитектуру проекта и код страницы университетов.
2. Найти причину существующей ошибки и выяснить, почему предыдущая реализация не работает.
3. Проверить существующие маршруты, фильтры, компоненты и структуру данных.
4. Составить короткий план исправлений.
5. Внести минимальные необходимые изменения, переиспользуя существующий код.
6. Проверить работу всех сценариев после изменений.

Не удалять существующий функционал ради новой реализации. Не менять API, базу данных или схему данных без подтверждённой необходимости.

## 5. Критерии готовности

Работа считается выполненной, если:

- общий каталог университетов работает как раньше;
- фильтрация по странам работает корректно;
- при выборе страны открывается её отдельная страница;
- на странице отображается информация о стране;
- сначала показываются топ-20 университетов, затем остальные;
- все переходы, карточки и фильтры работают корректно;
- дизайн соответствует существующему сайту;
- остальные страницы и функции не сломаны;
- отсутствуют ошибки сборки и консоли, связанные с внесёнными изменениями.

**Главное требование:** сначала разобраться в существующем коде и исправить текущую реализацию, а не создавать новую систему поверх старой. Если для выполнения задачи не хватает данных или обнаружена архитектурная проблема, сначала объяснить её и предложить решение, не внося масштабных изменений без согласования.
