# ZagranEasy Platform — Полные требования

## Что мы строим

ZagranEasy — это **платформа**, а не сайт-визитка.

Разница:
- Сайт-визитка: "мы оказываем услуги, вот телефон"
- Платформа: "вот вся информация, выбери, сравни, посчитай, пойми — и мы поможем оформить"

Человек приходит с вопросом: **"Как мне поступить/уехать/жить за границей?"**
Платформа отвечает на ВЕСЬ вопрос — от выбора страны до первого дня на месте.

---

## Главная идея

> Одна платформа решает все вопросы жизни за рубежом:
> учёба, путешествия, работа, виза, жильё.
> Полная информация + сопровождение под ключ.

## Модуль 1: Образование

### Что должен получить пользователь

Пользователь пришёл и хочет знать ВСЁ:

#### Уровень 1 — Выбор страны
- Какие страны доступны (9 стран)
- Чем отличается каждая: стоимость жизни, язык, культура, безопасность
- Какие гранты/стипендии есть в каждой стране
- Какой климат, часовой пояс, расстояние от Казахстана
- Сколько стоит жизнь в месяц (еда, жильё, транспорт)

#### Уровень 2 — Выбор университета
- Список всех университетов в выбранной стране
- Фильтры: государственный/частный, язык обучения, наличие гранта, город, программа
- Каждый университет: рейтинг, программы, стоимость, общежитие, требования
- Сравнение 2-3 университетов рядом (таблица)
- Фото кампуса, карта расположения

#### Уровень 3 — Как поступить
- Пошаговый процесс (8 шагов) для каждой страны
- Какие документы нужны (чеклист с галочками)
- Дедлайны подачи (когда начинать, когда крайний срок)
- Стоимость процесса (консульский сбор, перевод документов, апостиль)
- Калькулятор: "сколько мне будет стоить поступление"

#### Уровень 4 — Жизнь студента
- Как выглядит обычный день студента
- Общежитие: фото, стоимость, условия
- Еда: столовая, кафе, сколько стоит
- Транспорт: как добираться, стоимость проездного
- Работа во время учёбы: можно ли, сколько часов, какая зарплата
- Безопасность, медицина, связь

#### Уровень 5 — Город
- Гайд по городу: районы, достопримечательности, климат
- Казахстанская/студенческая диаспора
- Полезные контакты: посольство, экстренные службы
- Карта с отмеченными точками (университет, общежитие, магазины)

### Страницы модуля Образование

```
/education                        ← Каталог стран + обзор
/education/[country]              ← Страница страны (вузы + жизнь + город)
/education/[country]/[university] ← Детальная страница вуза (будущая фаза)
/education/compare                ← Сравнение вузов (будущая фаза)
/education/deadlines              ← Календарь дедлайнов (будущая фаза)
/education/documents              ← Чеклист документов (будущая фаза)
/education/calculator             ← Калькулятор стоимости обучения
```

### Данные для каждой страны

```
Страна:
  - Название (RU, EN, KZ)
  - Флаг, континент
  - Описание (короткое для карточки + длинное для страницы)
  - Города для обучения
  - Стоимость жизни в месяц (общежитие, еда, транспорт)
  - Средняя зарплата студента (если можно работать)
  - Язык обучения, нужен ли сертификат
  - Климат, часовой пояс
  - Расстояние от Алматы (часы перелёта)
  - Требования к поступлению (документы, экзамены)
  - Доступные гранты/стипендии
  - Фото (hero, gallery)
  - Количество вузов

Университет:
  - Название, город, тип (гос/частный)
  - Рейтинг (национальный, мировой)
  - Программы (бакалавр, магистр, PhD, языковой год)
  - Языки обучения
  - Стоимость обучения (от — до, за год)
  - Есть ли грант, детали гранта
  - Общежитие: есть/нет, стоимость
  - Требования к поступлению
  - Фото кампуса
  - Ссылка на официальный сайт
  - Дедлайны подачи

Программа (детально):
  - Название, уровень, язык
  - Длительность
  - Стоимость за год
  - Требования
  - Есть ли грант
```

## Модуль 2: Туры

### Что должен получить пользователь

Не просто "купи тур" — а полная картина поездки:

#### Уровень 1 — Выбор направления
- Какие туры доступны
- Фильтры: регион, бюджет, длительность, тип (пляж, экскурсия, adventure)
- Карточки с фото, ценой, длительностью, звёздами отеля

#### Уровень 2 — Детали тура
- Полный маршрут по дням (day 1, day 2, ...)
- Что включено (перелёт, отель, еда, экскурсии, страховка, виза, трансфер)
- Что НЕ включено
- Фотогалерея
- Цена и что влияет на стоимость
- Рассрочка 0·0·12

#### Уровень 3 — Гайд по стране/городу
- Что посмотреть помимо тура
- Местная кухня, что попробовать
- Валюта, язык, безопасность
- Что взять с собой
- Полезные фразы на местном языке
- Погода по месяцам

### Страницы модуля Туры

```
/tours                    ← Каталог туров
/tours/[slug]             ← Детальная страница тура (маршрут, цена, фото)
/tours/destinations       ← Гайды по странам/городам (будущая фаза)
```

## Общие компоненты платформы

### Навигация
- Navbar: логотип + 5 модулей + CTA
- Mobile: hamburger → drawer
- Breadcrumbs на каждой внутренней странице
- Sticky WhatsApp кнопка

### Поиск (будущая фаза)
- Глобальный поиск по всей платформе
- "Турция" → показывает: университеты + туры + работа + недвижимость в Турции

### Квиз
- 3 шага → рекомендация услуги → WhatsApp
- Доступен с главной и из любого модуля

### Калькулятор
- Публичный: ориентировочная стоимость для клиента
- Внутренний (staff): точный расчёт с разбивкой

### Мультиязычность
- Фаза 1: Русский
- Фаза 2: + Қазақша, English

## Гайды по городам (cross-module)

Каждый город, который фигурирует в образовании, турах, работе или недвижимости — имеет свой гайд:

```
Город:
  - Название, страна
  - Описание (климат, население, характер)
  - Стоимость жизни (аренда, еда, транспорт)
  - Фото и видео
  - Что посмотреть (топ-5 мест)
  - Безопасность (рейтинг)
  - Транспорт (как передвигаться)
  - Связь (какой оператор, интернет)
  - Казахстанская диаспора

Связи:
  - В этом городе учатся: [университеты]
  - В этом городе можно работать: [вакансии]
  - В этом городе есть жильё: [объекты]
  - Тур в этот город: [туры]
```

Это создаёт **сеть**: Стамбул → можно учиться (3 вуза) + можно работать + можно купить жильё + тур.
