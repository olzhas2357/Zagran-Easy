# Supabase — миграции

Порядок применения (SQL Editor в панели Supabase → New query → вставить → Run):

1. `migrations/0001_init.sql` — схема (таблицы, RLS, триггер профиля).
   Внутри есть `drop table if exists ...` для старых пустых таблиц
   (`education_countries`, `universities`, `tours`, `work_countries`,
   `properties`, `reviews`, `leads`) — проверено через REST API, что
   они пустые. Если в них уже есть реальные данные — не запускайте,
   сначала выгрузите данные.
2. `migrations/0002_seed.sql` — тестовые данные (4 страны, 7 вузов,
   3 тура, отзывы и т.д.), те же, что сейчас в `data/*.ts`.
3. `migrations/0003_turkey_universities_update.sql` — заменяет 3 старых
   вуза Турции на полный список из 8 (источник: `turkey_education_data.json`,
   тот же список уже перенесён в `data/education.ts`). Применять один раз,
   после 0001+0002.
4. `migrations/0004_university_photos.sql` — добавляет колонки
   `gallery_images` и `dormitory_images` (фото кампуса и общежития на
   странице вуза, редактируются в /staff/universities).
5. `migrations/0005_university_media_storage.sql` — создаёт бакет
   `university-media` (публичный) для загрузки фото/презентаций прямо
   из кабинета менеджера, с политиками доступа (запись — только staff).
6. `migrations/20260914085103_normalize_university_catalog.sql` — создаёт
   таблицы программ, наборов, требований, стоимости и стипендий.
   Применить до добавления Spring 2027.
7. `migrations/20261017160000_china_spring_2027_catalog.sql` — идемпотентно
   добавляет весенние программы 2027 для шести университетов Китая,
   используя существующие записи университетов и не создавая дубликаты.
   Данные не сверены с официальными источниками; неподтверждённые даты
   не записываются как календарные дедлайны.
8. `migrations/20261021180000_china_top_universities.sql` — добавляет
   университеты из гида по Китаю, не создавая дубликаты уже существующих
   записей. Официальные сайты и направления добавляются как справочные
   данные; неизвестные цены, программы поступления, требования и медиа
   оставляются незаполненными до проверки. Применять после миграций 6–7.
9. `migrations/20261021190000_china_campus_photos.sql` — добавляет поля
   атрибуции изображения и фотографии кампусов пяти вузов из топ-5 Китая.
   Существующее изображение вуза не перезаписывается. Применять после
   миграции списка китайских университетов.
10. `migrations/20261106130000_localize_shenzhen_phd_degree.sql` — приводит
   уровень программы Shenzhen University к русскому отображению
   «Докторантура (PhD)». Безопасно повторно запускать.

После применения:

- Фронтенд получает публичный каталог через NestJS API (`NEXT_PUBLIC_API_URL`,
  см. `lib/data.ts`). SQL-миграции применяются отдельно в проекте Supabase;
  для их запуска нужен доступ к SQL Editor или к базе данных.
- Чтобы завести первого сотрудника (менеджера/админа): зарегистрируйте
  пользователя через Supabase Auth (Dashboard → Authentication → Add user,
  или форму на `/staff/login` после того как она появится), профиль
  создастся автоматически с ролью `manager`. Чтобы сделать его `admin`,
  выполните в SQL Editor:
  ```sql
  update profiles set role = 'admin' where id = '<user-id>';
  ```
